蚂蚁集团

蚁小保

面向选品、投保、退保等保险服务的多 Agent 应用。协调者和领域专家一起处理跨业务任务，IM 对话延伸到图片问答、实时语音，以及边看边聊。

主导相机、实时音视频的架构设计与落地；作为核心成员深度参与 IM 多智能体架构、会话状态与路由设计。

实时音视频与话轮上下文

主导实时音视频架构，把媒体交互和业务推理解开。链路是 VAD / ASR，然后模型推理，再 TTS。用户可以插话打断，系统同时播报。

视频用 VAD 的起止圈定这一轮话里的帧上传窗口，旁路模型判断画面是否有效。话轮结束时，视频信息和 ASR 文本一起交给多模态模型，把这一轮所说和所见连上。语音和视频共用 TTS 与客户端播报。

IM 多智能体协同

深度参与基于 LangGraph 的协调者与专家 Agent。统一的 Graph State 放计划、槽位、执行状态、结果和 Trace，任务可以线性、并行或混合。

路由结合粗分流、槽位校验和澄清补齐。项目评测里，路由准确率达到 90%。协调者可以直接应答，大小模型分工，用来控制调用开销。

参与 Answer Chunk 和两阶段准出方案。长任务的输出和收敛，看阶段反馈、专家证据、任务完成度，以及迭代上限。

图片问答与用户 Workspace

主导拍照和图片文件对话。外部图像摘要服务把理赔照片等材料转成 System Prompt 里的上下文，模型据此做业务问答。个人用户 Workspace 接着收材料，并承接后面的对话。
