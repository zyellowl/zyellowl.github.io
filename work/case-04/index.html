2023 年京东云峰会宣讲初版 MVP 的核心研发成员，负责数据分析洞察模块。统一 RAG 平台独立负责。

对话式营销工作台

基于 SOP 和多轮对话，把营销费用申请、活动策划、人群推送和数据分析串成一个工作台。

复杂查询上，用 Dynamic Few-shot 加 CoT 组织 Prompt，用 Schema Linking 筛出相关的表和字段，让生成依据停在当前问题需要的结构和示例上。

SQL 执行结果再接回修正流程，处理复杂 Join 和字段引用。领域内 SQL 准确率从 40% 提到 92%。

统一 RAG 平台

把文档解析、向量化和检索收成一个平台，让不同业务接入知识问答。

基于 Qdrant 管理文档、切片、Embedding 和向量集合的关系，围绕文件解析、数据无感更新和 Embedding 绑定来入库、维护。

声明式 API 把底层向量能力交给业务调用，支持向量集群自动扩缩容。
