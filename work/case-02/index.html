蚂蚁集团

大保 Harness

面向蚁小保持续迭代的 Agent Harness，以大保 CLI 为统一内核。定时任务通过 CLI 驱动一条由生产反馈触发的自迭代：生产回流，问题发现，分级修复，沙箱验证，评测门禁，再发布回流。同一套 CLI 再以钉钉 Bot 为入口开放给团队。

深度参与大保 Hub、CLI 及配套 Skill，参与自迭代里的问题发现、治理修复和实验验证。负责大保 Bot 的构建，基于本机运行时调度 Codex，并把结果发到钉钉。

Trace 驱动的问题发现

线上对话和执行 Trace 回到治理链路，覆盖工具调用、上下文组装，以及 Agent 与子 Agent 的路径。定时任务循环扫描，用规则评测和模型语义评测检查回答和执行链路，按问题类型进入治理。诊断和修复可以回到原始执行证据。

自动修复与验证闭环

部分简单问题会自动修复。Prompt 等治理改动放进 Sandbox，在按生产标准复刻的环境里复现并验证。通过评测门禁后合并，随发布班车上线，再用新产生的对话 Trace 做下一轮检查。

Hub 与编码 Agent

Hub 承载问题、治理、实验和评测。CLI 与 Skill 向 Codex、Claude Code 等编码 Agent 提供经过企业登录和鉴权的日志与上下文，把线上执行证据接到研发诊断，让编码 Agent 按完整调用链看问题。

大保 Bot

钉钉 Bot 是团队入口，底层复用大保 CLI。本机运行时调度 Codex，做问题排查、文档撰写和总结，再把结果回传到群聊。

组里每个人把自己负责的模块沉淀成 Harness：上下文、排查手册和 Skill。Bot 按需加载、组合。团队知识从文档和口口相传，变成 Agent 可以执行的能力。Bot 再按 Harness 的归属，呈现各模块的负责人、贡献，以及业务链路怎么跑。
