计划里写了先读后写，日志里写插了进来

我把读做成会睡一会儿的假工具。睡眠期间如果出现写的提议，就计数。计数大于零，就是宿主没拦住。这个测试不看它的解释，解释会说自己没有插队。

没有读的结果，写的提议直接拒绝。拒绝不看它在计划里怎么保证。

两个只读可以重叠。一个写不和别的重叠。重叠与否看工具种类，不看句子里有没有“同时”。

推理文本留着给我读，程序只看调用记录。两个测试文件分开，免得我为了句子好看把锁放宽。

睡眠设了 3 秒。这 3 秒里写提议的计数如果不是 0，测试失败。数字只服务这个测试，不拿去跟别的模型比速度。

睡眠那 3 秒只服务这个测试。计数不是 0 就失败。我不拿这个秒数去跟别的模型比快慢。

这 3 秒只属于这个测试。我不把秒数写进别的笔记里当速度结论。

测试文件名里写着顺序，不写着模型名。

假工具睡了 400 毫秒。睡眠里出现写，计数加一。那次计数是 1。
