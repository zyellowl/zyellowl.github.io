用 MCP 挂了一个只读工具

十二月说它是草案。二月给自己挂了一个：列出笔记标题。没有写入，没有网络。

发现失败和调用失败在日志里是两行不同的字。这比全写进一个提示清楚。空列表回来，给出去的还是“没取到”，校验在我这边，协议没替我停。

描述我改了三版，每版都看调用有没有变宽。用了助手、自动之后，它更常在空列表后面继续说。那些词删了。

超时沿用场景常数，不抄示例里的感觉。开口的回合里我不走发现，发现本身也要时间。

第二个工具先不挂。要是会写，得先有调用编号。编号是我自己的旧习惯，不是这个协议的卖点。

描述的三个版本按日期躺在一个目录。中间那版出现了“自动整理”。那一版的日志里，空列表之后还有一段话。前后两版没有。

中间那版描述我没删文件，只是不再用。对照还在，能看见词怎么把调用带宽。

标题列表为空的那次，日志第二行写的是调用失败。发现那一行是空的。
