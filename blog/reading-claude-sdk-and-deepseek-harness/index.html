result 未结束，append 未落盘

Claude Code 本体不是公开源码。我打开的是 claude-agent-sdk-python，看它怎么拉起 CLI、stdout 上除了文本还有没有控制消息。有。权限一类的请求会从子进程绕回来。我没据此去猜 CLI 里面怎么规划。

有一段注释让我停下来：拿到 result 也不等于事情结束，因为还可能有没完成的任务。我把这句抄在旁边。抄注释比自己总结安全。

DeepSeek Harness 的公开仓库里，session.append 看下来是先进入内存里的序列。写盘是后面的事。我以前会把 append 说成已经落盘，这次不敢这么说了。

压缩在它那里更像给模型换一份更短的视图，原来的事件还留着。我只读了相关的几段和测试名，没有把整个仓库读完。

四家放一起我没有做表。表会逼我填没读过的格子。八月就这两篇笔记，够用了。

抄下来的注释我标了文件名。没有文件名的句子我不当成读过代码。免得下周把自己的猜测和注释混在一起。

注释旁边写了文件名。没有文件名的句子，我后面会把它当成自己的结论。
