Claude 3 让我改了评测样本，不是改了信仰

三月初 Claude 3 发布。我把它放进同一小套离线样本：旁白留空、检索引用、空检索时必须停。样本不多，是我手写并手核过的。换模型的第一天，我不增加新题。

文体立刻不同。句子更稳，拒绝时也更会解释。解释很礼貌，有时礼貌本身在掩盖没有停住。我把“解释完仍然给了一个猜测”算作失败。按这个标准，它比我习惯的接口好一些，没有全过。

空检索的题目最有用。材料明确是空的，它有时说无法回答，有时根据问题本身编一段常识。常识在聊天里友善，在记录问答里是污染。这个失败形状我认识，不是新模型特有的。

所以我没有写“换成 Claude”。我改的是样本说明：礼貌的猜测也算编造。旧样本把这个算得太松，只抓明显的假物体。新模型让松的地方露出来，这是发布周对我最有用的地方。

速度和价格我没有认真比。一个下午的感觉不能当结论。我只记下：要复查的时候，两家接口都还能用，选择取决于哪一家在这套样本上的失败我更能看懂。

信仰如果是指“更强的模型会取消核对”，那我没有改信仰。样本变严了。核对还在。

这次也提醒我，评测集要版本化。我改了判定，就该留下旧判定下的结果。不然下周会以为模型退步了，其实是我变严了。

三月的动作就这两件：样本加严，结果按版本留底。模型名字写在记录里，不写在标题的结论里。

旧判定和新判定的两次结果都留在同一题号下。题号不变，判定版本变。这样我不会把判定变严说成模型变差，也不会把礼貌变多说成任务通过。

题号不变还有一个好处：我可以告诉以后的自己，哪一天判定变了。日期写在判定文件头上。没有日期的判定，会伪装成从来如此。

样本文件头部写着判定版本。版本不对，脚本拒绝跑。这个小门槛省掉了我把不同年份的通过率放在一起看的错误。
