Claude 3 发布当周，我先跑旧题

句子更稳，拒绝的时候也更会解释。解释很客气，客气完有时还是给了一个猜测。我把“解释完仍猜了”算失败。按这个标准，比我常用的接口好一些，没有全过。

空检索那题最有用。材料写明是空的，它有时说没法答，有时根据问题讲一段常识。常识在聊天里挺友善，拿来当记录就是脏的。

我改的是题的说明，不是把日常调用换成 Claude。判定变严了就另存一版，旧结果留在同一个题号下面。不然下周会以为模型退步了。

一个下午比不出价格和速度，我没写。

同一题号下面有两份判定。我文件名里写了日期。打开时先看日期，免得把变严之后的失败说成模型退步。

同一题号两份判定，文件名里写日期。打开先看日期，免得把我变严说成它变差。

判定文件头上的日期我每次打开都先看。不看的话，变严会被说成退步。

日期写在文件名里，打开不用先读正文。

旧题文件没改日期。跑的记录另存，文件名用 0304。
