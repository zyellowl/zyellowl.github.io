例子比禁令更容易带偏

二月开始认真写提示，写成配置文件那样，分节、列禁令、给例子。同一段旁白多跑几次，格式还在，内容会漂。有一回它顺着例子里的“建议”开始给建议，我那节明明写的是只改写观察。

把角色写成“你是审慎的摄像师”，旁白腔立刻上来，事实没更稳。角色只管语气。

禁令我从前到后贴了三遍“不要编造”。看着很谨慎，跑起来该补的还是补。后来每次只改一行，把改之前的输出留下。三次对不上，就先别加新规则。

情人节那天把两页删成半页。演示没那么好看，我自己复查快了。

三次对不上的那份我没再修，文件名就叫不稳定，跟新的半页放一起。打开半页的时候会看见它。

半页模板每次只许加一行。加之前的输出还在。我要是说不清这行改变了哪一次跑的结果，这行就删掉。
