GPT-5 当周不改失败判定

有的题过得更干脆，有的失败时更会解释。解释不改变失败。空结果后面的建议还是失败。

输出按模型版本存，判定版本不动。2024 年 3 月 Claude 3 那周也是这么干的。每次发布都想改题，用同一个动作挡。

默认模型当天没切。配置注释里写了解冻条件：某一题的失败要能用事件解释。没有事件的变好，不改默认。发布周我打开配置看过一眼，确认自己没临时改。
