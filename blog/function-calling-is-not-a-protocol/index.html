窄函数仍会给出越界参数

函数我写得很窄，只收我记录里有过的动作词。跑下来三种结果都有：参数合法，参数越界，或者它根本不调用、自己写一段。只处理第一种的话，演示好看，另外两种会沉默。

说明写长，它更爱调用；写短，它更爱直接回答。我没找到一个写完就稳定的版本。这跟服务端那种非法输入会被拒绝的协议还不一样，它经常自己绕开。

脚本里我记三行：它提出了什么，我拒了没有，有没有真的执行。缺一行就当这次没发生。拒绝之后不许再写散文把动作做完，那等于把函数调用绕过去。

还没接到真设备上。能提出调用，不等于我让它执行。

拒绝之后它有时会换个参数再提议。第二次还是经常越界。我就把拒绝当成这次的结束，不在同一次里跟它商量。商量要我另外开一轮。

同一次里的第二次提议我直接丢掉，不记录成协商。协商如果要做，得是我新开的一轮，带一个新的编号。
