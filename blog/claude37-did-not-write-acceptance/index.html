Claude 3.7 的长思考，没有替我写出验收

二月末 Claude 3.7 把更长的思考带到台前。我还是用那套短题集，不新编“更能体现思考”的题。新编题目是在为模型选美。

展示出来的思考让复查变容易，也变危险。容易是因为我能看见它往哪边想。危险是因为思考写得诚恳时，我会想放宽失败。诚恳不是通过。

有一题空结果，它思考了很久，最后仍给了一段常识性的建议。按验收这是失败。如果没有事先写好的句子，我很可能在笔记里夸它谨慎。

所以长思考改变的是可观察性，不是标准。可观察性欢迎。标准不动。标准一动，这个月的模型和上个月就不能比。

我把思考文本存下来，但存在单独字段，不和工具结果混。混了以后，引用检查会把思考当成原文。思考不是原文。

速度上它不进入开口回合。理由和一月对 R1 一样。重复不是因为懒，是因为这条边界还没有被新发布推翻。

二月就这样结束。两个新模型，同一套题，同一条禁令：不要因为过程变长而改判定。

判定文件的日期仍是旧的。我检查过，没有手滑。

思考字段的存储权限和原文不同。原文可以进引用检查，思考字段在检查脚本里被明确忽略。忽略要写在代码里。写在文档里，下一次有人会把它拼进上下文当证据。

当周我没有发长文评价这个模型。评价会逼我选边。选边之后，旧判定就很难保持不动。不动判定比发表看法重要。

思考字段被脚本忽略这件事，我加了一条测试：字段里放入一条假引用，检查结果必须仍然失败。测试防止以后有人把思考拼回证据。拼回去，这次的克制就没了。

我又把当天的输入和输出各存了一份，不把结论写进文件名。文件名只写日期。结论写在正文里。正文可以错，文件还在，就能对照。对照时先看自己有没有把未知说成完成。说成完成的那一句划掉，但不删文件。划掉是为了以后看见自己当时多想结束这件事。输入输出都保留，避免只留下好看的那一稿。
