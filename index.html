AI Agent 开发工程师

10 年研发经验，2023 年起从事大模型应用研发，逐步深入多智能体、实时多模态与 Agent Harness。主导蚁小保相机与实时音视频，深度参与 IM 多智能体及大保自迭代 Loop，构建基于大保 CLI 的团队协作 Bot。自研对话式用户分析洞察工具，负责后训练评测挖掘平台。具备金融业务后端与性能优化基础，工程实践覆盖数据生产、Agent 交互，以及线上问题发现、修复与验证。

工作

蚁小保
蚂蚁集团。面向选品、投保、退保等保险服务的多 Agent 应用。协调者和领域专家一起处理跨业务任务，IM 对话延伸到图片问答、实时语音，以及边看边聊。

大保 Harness
蚂蚁集团。面向蚁小保持续迭代的 Agent Harness，以大保 CLI 为统一内核。定时任务通过 CLI 驱动一条由生产反馈触发的自迭代：生产回流，问题发现，分级修复，沙箱验证，评测门禁，再发布回流。同一套 CLI 再以钉钉 Bot 为入口开放给团队。

数据工厂
蚂蚁集团。面向大模型后训练的数据质量迭代，把生产数据回流、样本加工、质量校验和评测挖掘接在一起。同时自研一套对话式的用户分析工具，用自然语言看用户行为。

京东领航者
京东集团。用对话串起营销费用、活动、人群和数据分析，并独立做了统一 RAG 平台。2023 年京东云峰会宣讲过初版。

京东金融首页 Feed
京东集团。内容规模扩大到原来的 20 倍，服务要同时守住内存、吞吐和尾延时。

京东金融智能问答
京东集团。让金融问答的流程可以配置、可以迭代，同时线上正在进行的会话不要断。

在线商城与异常检测
高思教育。参与 ToB 和 ToC 商城，并独立做了一套业务数据异常检测。

信贷基础服务平台
百度金融。2017 年 6 月到 2020 年 5 月，参与信贷基础服务平台从零搭建，为风控、交易、分发和核心系统提供统一助贷能力。

会用的东西

语言主要是 Java、Python、TypeScript、JavaScript 和 SQL。

Agent 这边常用 LangGraph、LangChain、ReAct、Function Calling、Skill、MCP，以及会话状态和任务编排。上下文和评测包括 Prompt、工具返回值裁剪、Trace、HITL、Sandbox 和评测门禁。

多模态是图像上下文、Workspace、VAD、ASR、TTS、实时打断，以及视频话轮。检索和数据是 RAG、NL2SQL、NL2DSL、Qdrant、Elasticsearch 和数据回流。

服务端是 Spring 全家桶、MyBatis、Redis、Kafka、RabbitMQ。性能上做过 MySQL、索引、分库分表、JVM 和接口优化。工程上用 Git、Docker、K8S，以及 Codex、Claude Code、Cursor。

黑龙江八一农垦大学，计算机科学与技术，本科，2013 到 2017。
